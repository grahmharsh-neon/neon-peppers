NEON PEPPERS COA REBUILD V17

CHANGES
- Add COA exists only on /coa-admin.html.
- Removed COA add/edit controls from the main Admin dashboard.
- Standalone COA Admin has its own login, product loading, editor, upload, and delete logic.
- Public COA Library remains at /coa.html.
- Public COAs remain available on individual product pages.
- Supported files: PDF, PNG, JPG, JPEG.
- Maximum file size: 10 MB.

INSTALL
1. Unzip this package.
2. Copy all files into Documents\GitHub\neon-peppers.
3. Keep config.js.
4. Run supabase-coa-rebuild-v17.sql in Supabase SQL Editor.
5. Commit and push.
6. Refresh with Ctrl + F5.
