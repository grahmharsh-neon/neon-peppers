NEON PEPPERS V24.1 — COLLAPSIBLE PRODUCTS

Products Admin is now collapsible.

COLLAPSED BY DEFAULT
Each product shows:
- Product name
- Lifecycle
- Sizes
- Price
- Stock
- Missing Image warning
- Missing Price warning
- Missing Description warning
- No Sizes warning
- Low Stock warning
- Edit / Expand

EXPANDED
Click the row to reveal the full existing product editor.

CONTROLS
- Expand All
- Collapse All
- New products automatically expand

No Supabase changes are required.

INSTALL
1. Replace your project files with this package.
2. Keep config.js.
3. Commit and push.
4. Hard refresh /admin.html#productsPanel with Ctrl + F5.
