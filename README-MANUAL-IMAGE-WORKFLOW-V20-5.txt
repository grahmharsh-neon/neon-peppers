PRODUCT WORKFLOW
1. Enter product name, strength, category, and price.
2. Click Generate Description.
3. In ChatGPT, request the matching Neon Peppers vial image.
4. Download the approved image from ChatGPT.
5. Upload it in Admin as the product image.
6. Save Product.
7. Upload the COA separately when available.

INSTALL
1. Unzip this package.
2. Copy all files into Documents\GitHub\neon-peppers.
3. Choose Replace files.
4. Keep config.js.
5. Commit and push.
6. Wait for Netlify to deploy.
7. Refresh Admin with Ctrl + F5.

No Supabase changes are required.
Existing product images remain unchanged.
