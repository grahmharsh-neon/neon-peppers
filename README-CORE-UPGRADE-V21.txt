NEON PEPPERS CORE BUSINESS UPGRADE V21

ADDED
- Inventory counts and low-stock alerts
- Optional hide when out of stock
- Product tags and aliases
- Better public and Admin search
- Private supplier, unit cost, shelf location, and notes
- Automatic URL slugs
- SEO title and meta description
- Basic product view/search/order analytics table
- Customer confirmation email after Order Request
- Inventory-aware Order Request availability

INSTALL
1. Copy files into your Neon Peppers project.
2. Keep config.js.
3. Run supabase-core-upgrade-v21.sql in Supabase.
4. Commit and push.
5. Hard refresh with Ctrl + F5.

NOT INCLUDED
- Card payments
- Shipping-label purchasing
- Customer login portal
Those require separate provider and authentication setup.
