NEON PEPPERS ORDER REQUEST SYSTEM V7

Adds:
- /order.html research order request form
- Popular product starter list
- Editable strengths and stock status in Admin
- Available, Low Stock, Out of Stock, Coming Soon
- Quantity cart
- Supabase order records
- Email notification
- Admin Order Requests page

Install:
1. Copy all files into Documents\GitHub\neon-peppers.
2. Keep your current config.js.
3. Run supabase-order-requests-v7.sql in Supabase SQL Editor.
4. Commit and push in GitHub Desktop.
5. Refresh /admin.html and /order.html with Ctrl + F5.

The form is an order REQUEST only. It does not process payments or automatically approve fulfillment.
