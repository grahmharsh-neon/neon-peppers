NEON PEPPERS ADMIN V5

NEW FEATURES
- Dashboard statistics
- Homepage editor
- Hero text and hero image editing
- Research-use strip editing
- Announcement bar
- Product search and filters
- Product status: Available, Coming Soon, Out of Stock
- Featured-product control
- Product-image uploads with browser optimization
- COA PDF uploads
- Contact email, footer disclaimer, and logo editing
- Public website reads settings directly from Supabase

INSTALL
1. Unzip this package.
2. Copy all files into your local Documents\GitHub\neon-peppers folder.
3. Replace existing files when prompted.
4. KEEP your existing config.js with your Supabase URL and publishable key.
5. In Supabase SQL Editor, run supabase-admin-v5.sql once.
6. In GitHub Desktop:
   Summary: Install Admin V5
   Commit to main
   Push origin
7. Wait for Netlify to publish.
8. Refresh /admin.html with Ctrl + F5.

SECURITY
Never place a Supabase secret key or service-role key in config.js.
