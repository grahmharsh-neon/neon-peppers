NEON PEPPERS CUSTOMER CRM V21.5

ADDED
- Standalone Customer CRM at /customer-crm.html
- Customer profiles created from Order Requests
- Customer contact information
- New, Active, VIP, and Inactive statuses
- Private customer notes
- Request history
- Invoice history
- Requested and paid totals
- Search by customer, email, phone, company, or product
- Quick links to email customers
- Quick links to open invoices
- New Invoice button from the customer profile
- New Order Requests automatically update the customer record

INSTALL
1. Copy all files into Documents\GitHub\neon-peppers.
2. Keep config.js.
3. Run supabase-customer-crm-v21-5.sql in Supabase SQL Editor.
4. Commit and push.
5. Hard refresh with Ctrl + F5.
