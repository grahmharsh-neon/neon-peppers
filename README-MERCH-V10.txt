NEON PEPPERS MERCH V10

ADDS
- Public merch page at /merch.html
- Shirts, hats, hoodies, stickers, and accessories
- Admin Merch section
- Editable names, categories, descriptions, prices, images, visibility, and sort order
- Editable sizes, colors, prices, and stock status
- Merch image upload through Supabase Storage
- Request This Item button opens an email to support@neonpeppers.com

INSTALL
1. Unzip this package.
2. Copy all files into Documents\GitHub\neon-peppers.
3. Keep your current config.js.
4. Run supabase-merch-v10.sql in Supabase SQL Editor.
5. Commit and push in GitHub Desktop.
6. Refresh /admin.html and /merch.html with Ctrl + F5.

ADMIN
Open Admin → Merch → + Add Merch Item.
