NEON PEPPERS V24.2 — SUPPLIER PRICING & MARGINS

ADDED
Private admin page:
/supplier-pricing.html

TRACK
- Product
- Size
- Supplier
- Supplier Cost
- Your Retail Price
- Profit per vial
- Margin %
- Quantity
- Inventory Cost
- Potential Retail Value
- Notes

FILTERS
- All
- Matched to Product
- Not Matched
- Margin under 40%

PRODUCT MATCHING
You can link a supplier price row to an existing Neon Peppers product.
When matched, the current product retail price is filled automatically.

PRIVATE
Supplier pricing is admin-only and never appears on the public website.

SUPABASE
Run:
supabase-v24-2-supplier-pricing.sql

INSTALL
1. Copy files into the Neon Peppers project.
2. Keep config.js.
3. Run supabase-v24-2-supplier-pricing.sql.
4. Commit and push.
5. Hard refresh Admin and /supplier-pricing.html with Ctrl + F5.

The uploaded supplier PDF can be used as the source for manually populating
this table now, and CSV/bulk import can be added next.
