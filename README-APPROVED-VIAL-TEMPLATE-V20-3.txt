NEON PEPPERS APPROVED VIAL TEMPLATE V20.3

CHANGES
- Adds the approved Neon Peppers vial image directly to the site.
- Generate Product Image uses it automatically as the default template.
- No separate upload is required.
- The template remains visible under Admin → Contact & Settings.
- You can still replace the template later if needed.

DEFAULT TEMPLATE
/assets/neon-peppers-approved-vial-template.png

INSTALL
1. Unzip this package.
2. Copy all files into Documents\GitHub\neon-peppers.
3. Choose Replace files.
4. Keep config.js.
5. Run supabase-approved-vial-template-v20-3.sql in Supabase SQL Editor.
6. Commit and push.
7. Refresh Admin with Ctrl + F5.

USE
1. Open Admin → Products.
2. Enter product name and strength.
3. Click Generate Product Image.
4. The builder uses the approved vial template automatically.
