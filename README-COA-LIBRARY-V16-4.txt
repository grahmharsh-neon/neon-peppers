NEON PEPPERS COA LIBRARY V16.4

FIXES
- Replaces the Add COA button logic with a direct event-delegated control.
- Loads products independently if Admin has not loaded them.
- Adds clearer Supabase errors.
- Adds a public COA Library at /coa.html.
- Adds COAs to the main navigation.
- Keeps public COAs on individual product pages.

INSTALL
1. Copy all files into Documents\GitHub\neon-peppers.
2. Keep config.js.
3. Run supabase-coa-library-v16-4.sql in Supabase SQL Editor.
4. Commit and push.
5. Refresh Admin with Ctrl + F5.
6. Open Admin → COAs → + Add COA.
7. Public library: https://neonpeppers.com/coa.html
