NEON PEPPERS TWO-BUTTON AI TOOLS V20.1

CHANGES
- Removed Regenerate Description wording.
- Removed AI Build Product.
- Added one Generate Description button.
- Added one Generate Product Image button.
- Generate Description changes only the description.
- Generate Product Image changes only the product image.
- Preview button remains for description formatting.

WORKFLOW
1. Enter product name.
2. Enter strength.
3. Click Generate Description.
4. Click Generate Product Image.
5. Click Save Product.

IMAGE SETUP
The Generate Product Image button still uses the approved vial template stored
under Admin → Contact & Settings.

INSTALL
1. Unzip this package.
2. Copy all files into Documents\GitHub\neon-peppers.
3. Choose Replace files.
4. Keep config.js.
5. Commit and push.
6. Refresh Admin with Ctrl + F5.

No new Supabase changes are required if the V20 AI Product Builder SQL was already run.
