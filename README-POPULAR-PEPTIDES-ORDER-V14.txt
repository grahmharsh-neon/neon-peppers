INSTALL
1. Unzip this package.
2. Copy all files into:
   Documents\GitHub\neon-peppers
3. Choose Replace files.
4. Keep your existing config.js.
5. In Supabase SQL Editor, run:
   supabase-popular-peptides-order-v14.sql
6. Commit and push in GitHub Desktop.
7. Refresh /admin.html, /order.html, and product pages using Ctrl + F5.

IMPORTANT
The SQL adds missing items and strengths without deleting your existing order-form items.
You can hide, rename, reorder, or delete items later from Admin.
