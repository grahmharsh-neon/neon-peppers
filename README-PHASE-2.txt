3. Choose Replace files.
4. Keep your existing config.js if Windows asks.
5. GitHub Desktop summary: Install Phase 2 catalog
6. Commit to main.
7. Push origin.
8. Wait for Netlify to publish.
9. Refresh the site with Ctrl + F5.

No new Supabase SQL is required if Admin V5 is already installed.
